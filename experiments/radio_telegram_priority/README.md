# Radio-telegram priority: p128 A1 and A2

Prepared by **icekylinx and GPT-6 Astra Pro**. This package independently
verifies the [two-part p128 source edition](../../cases/radio/telegram_priority.md):
a request for replies and brief plaintext instructions, followed by a
suggestion that the radio station give these telegrams precedence. The
literal signature is `HORSTMANN`.

| Record | Printed slots | Valid coordinates | Raw fixed plaintext labels | Known-coordinate substitutions | Printed-dash fills |
| --- | ---: | ---: | ---: | ---: | ---: |
| p128 A1 | 226 | 226 | 113 / 113 | 1 | 0 |
| p128 A2 | 282 | 275 | 134 / 141 | 5 | 7 |
| Total | 508 | 501 | 247 / 254 | 6 | 7 |

Both are ordinary exact-length frames under the unchanged published
`Nov4-6` key. No coordinate insertion, deletion, reorder or square completion
is used. A2's earlier 281-slot OCR candidate was a transcription error;
manual inspection finds the printed 282 slots, matching its length label.

## Preserved details

- A1 message number `597` and references `569`, `592`, `598` are unchanged.
- A2's raw `9` in `ANH9IM` and `7` in `IC7` are explicitly repaired by local
  coordinate substitutions. The raw strings and numerical ledger preserve
  them; no square digit is reassigned.
- Literal `AUSDRUEKLICH` and `WERDN` remain. No extra plaintext letters are
  silently inserted to modernize the spelling.
- `HORSTMANN` is an unchanged source reading, without a historical identity
  assignment. `ANHEIMGESTELLT` is presented as a suggestion, not as proof that
  radio priority had already been ordered or implemented.

## Reproduction

```sh
python experiments/radio_telegram_priority/verify.py --verify
```

Default verification uses the Python standard library and imports no shared
cipher code. It checks every source-image hash, manual group, source length,
label domain, numerical exception, repair ledger and exact forward witness.
The independently implemented transposition reconstruction follows sorted
column ranks, variable column heights and row-order reconstruction.

Optional PDF verification requires PyMuPDF and regenerates all three images
from the preserved page number, rectangles and scales:

```sh
python experiments/radio_telegram_priority/verify.py --verify \
  --pdf /path/to/adfgvx-childs.pdf
```

PDF SHA-256:
`157e41a12374c6c1f464f52f587fbf6be6e0e08706ac35f7f4b0d66dc798ad06`.
Printed p128 is PDF p131. `inputs.json` pins both PNG-file hashes and raw-pixel
hashes; the latter are checked against the PDF renderer. Default verification
and full PDF regeneration both passed.

`certificates.json` is reproducibly generated by running the verifier without
`--verify`. The original source and proposed reading remain separate, with
all changes priced rather than folded into the transcription. There is no
search model, trained corpus or heuristic scorer required for this package.

## Prior work and limits

J. Rives Childs's intercept collection is the primary source. The period key
is prior work by **George Lasry, Ingo Niebel, Nils Kopal and Arno Wacker**,
[DOI 10.1080/01611194.2016.1169461](https://doi.org/10.1080/01611194.2016.1169461),
also given in George Lasry's 2017 key comment. The complete provenance record
is retained in `inputs.json`. Earlier unreviewed OCR candidates existed.
No explicit p128 A body example was located in the bounded author-paper
review, which is not a claim to universal first-decipherment priority.

An exact forward witness proves the claimed arithmetic and costs. It does
not prove that every repaired word has a unique historical interpretation,
that the radio station followed the suggested priority, or that the
unexpanded signature identifies a particular individual.
