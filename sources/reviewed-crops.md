## Verify

```sh
python -m pip install -r REQUIREMENTS.txt
python data/reviews/verify_source_image_publication.py
python data/reviews/verify_source_image_publication.py --pdf /path/to/childs.pdf
```

The default check validates all 40 PNG files, dimensions and decoded RGB hashes against the existing review references. Supplying the original PDF additionally reproduces every crop pixel. The original scan is pinned by SHA-256 `157e41a12374c6c1f464f52f587fbf6be6e0e08706ac35f7f4b0d66dc798ad06`.

The [publication manifest](../data/reviews/source_image_publication_20261103.json) joins the delivered files to the earlier evidence references. Cipher transcriptions, repair ledgers and historical credits remain in the linked editions.
